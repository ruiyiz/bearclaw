# Workflow examples

Reference copies of workflow definitions running on the owner's machine. The
live source of truth is `~/.bearclaw/workflows/<slug>.json`; these are snapshots
for reading and diffing, not loaded by anything.

| File               | What it shows                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `feed-triage.json` | The nightly RSS digest. Deterministic `shell` and `transform` nodes around two `agent` nodes; the send guard is an edge, marking items read is structurally after a confirmed send, the caught-up branch still refreshes the batch file, and the watchdog is `policies.alerts.on_missed`. The `send` node captures the outbound Gmail envelope so `batch` can carry the thread id, the run parks on a silent `human` step, and `act` applies the answer against **that run's** batch — so the same code path serves a dashboard answer and an email reply, and neither can act on a newer digest's numbers. |
